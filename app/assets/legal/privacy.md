# 우나보 개인정보 처리방침

시행일 2026-11-15 · 버전 4

우나보(Unavo, 이하 "앱")는 함께 이동하는 운전자들이 방을 만들어 음성으로 통화하고 서로의 차량 위치를 보는 서비스입니다. 앱이 어떤 정보를 어떤 목적으로 다루는지 아래에 밝힙니다.

## 1. 처리하는 개인정보 항목
- 계정: 로그인 아이디, 비밀번호(서버에는 솔트를 섞은 해시 값만 저장), 표시 이름, 가입 시각, 만 14세 이상 확인 시각
- 로그인 세션: 로그인 토큰(서버에는 해시 값만 저장)과 만료 시각
- 동의 기록: 이 방침과 위치정보 동의에 동의한 문서 버전과 시각
- 프로필 사진(선택): 내가 고른 사진첩 사진을 앱 안에서 정사각으로 잘라 256px 로 줄인 이미지, 또는 앱이 제공하는 기본 아바타 선택값
- 친구: 내가 등록한 친구의 아이디
- 방: 방 코드, 방 이름, 참여·퇴장 시각
- 통화 연결: 음성 통화를 연결하기 위한 신호 데이터(네트워크 주소 후보 포함). 통화는 참여자 기기 간에 직접 또는 앱 운영자가 운영하는 중계 서버를 거쳐 전달되며 서버는 통화 내용을 저장하지 않습니다.
- 위치: 내가 "위치 공유"를 켠 동안의 위도·경도·정확도·속도·진행 방향·시각. 자세한 내용은 「위치정보 수집·이용 동의」에 있습니다.
- 서비스 이용 기록: 서버 요청의 종류·경로·처리 결과·처리 시간·요청한 아이디, 방별 위치 전송 건수 집계, 중계 서버의 오류 기록에 남는 접속 IP 주소, 통화 중계 서버의 접속 사용자명. 위치 좌표·요청 본문·사진·인증 정보는 기록에 남기지 않습니다.
- 쿠키 등 자동 수집 장치는 사용하지 않습니다.

## 2. 처리 목적
- 같은 방 참여자 간 음성 통화 연결과 유지
- 같은 방 참여자에게 내 차 위치와 따라가는 앞차의 이동 경로 표시
- 앱 지도에 추천 경로를 그리기 위한 도로 경로 계산
- 친구 목록으로 방 초대
- 만 14세 미만 가입 차단과 동의 사실 확인
- 서비스 장애 확인과 부정 이용 대응(서비스 이용 기록)

## 3. 처리·보유 기간
- 위치: 방이 유지되는 동안만 서버 메모리에 둡니다. 위치 공유를 끄거나 방을 나가거나 방이 사라지면 즉시 삭제하고, 앱이 꺼지거나 통신이 끊긴 경우에는 최대 2분 안에 삭제합니다. 공유 중 이동 경로는 참여자별 최대 7,200개 표본까지만 메모리에 두며 디스크나 데이터베이스에 저장하지 않습니다.
- 추천 경로: 운영 서버는 요청 처리 중 메모리와 재시도를 위한 입력 정보(최대 120초)만 유지합니다. 앱은 현재 안내를 표시하는 메모리에만 응답을 두며, 종료 시 제거합니다. 완료 응답을 재사용하는 캐시나 파일 저장은 하지 않습니다. 제공처의 보유 조건은 §5와 같습니다.
- 통화 연결 신호 데이터: 통화 연결에 필요한 동안만 두고 방이 사라지면 삭제합니다.
- 방 기록: 마지막 참여자가 나가 방이 비면 방과 참여·퇴장 기록을 즉시 삭제합니다.
- 계정·친구·동의 기록: 계정 삭제를 요청하면 지체 없이 삭제합니다.
- 로그인 세션: 만료되거나 로그아웃하면 폐기합니다.
- 프로필 사진: 새 사진으로 바꾸거나 기본 아바타로 되돌리면 이전 사진을 즉시 삭제하고, 계정 삭제 시 함께 삭제합니다.
- 서비스 이용 기록: 30일 동안 보관한 뒤 삭제합니다.

## 4. 파기 절차와 방법
- 보유 기간이 끝나거나 처리 목적을 달성한 개인정보는 지체 없이 파기합니다.
- 데이터베이스 기록은 행을 삭제하고, 프로필 사진은 파일을 삭제하며, 메모리에만 있는 위치·이동 경로는 즉시 제거합니다.
- 서버 스냅샷이나 별도 백업을 운영하지 않으므로 삭제한 정보가 다른 곳에 남지 않습니다.

## 5. 제3자 제공
- 같은 방 참여자에게 내 표시 이름, 프로필 사진, 통화 상태, 위치(위치 공유를 켠 경우)가 보입니다. 제공 목적은 같은 방 안의 통화와 위치 표시이고, 참여자의 화면에만 보이며 방이 사라지면 함께 사라집니다.
- 추천 경로 계산 제공처: 네이버 클라우드 플랫폼 Maps(Directions 5). 따라가기 안내 시작 및 「합류 후 따라가기」 재계산 때 뒷차 출발 좌표와 앞차 기준점 좌표(P0 또는 J)를 제공합니다. P0는 안내를 시작할 때 고정한 앞차 위치, J는 앞차가 실제로 지나간 이동 경로에서 선택한 합류 지점입니다. 목적은 앱 지도에 추천 경로를 그리기 위한 도로 경로 계산입니다. 계정·이름·사진·방 코드·전체 이동 경로는 보내지 않습니다. 제공처의 보유 조건은 네이버 클라우드 플랫폼의 정책을 따릅니다.
- 앞차와 뒷차 모두 방 화면에서 추천 경로 계산의 제공처·항목·시점을 상태 문구로 확인할 수 있습니다.
- 지도 화면을 그리기 위해 네이버 지도 SDK가 보고 있는 지도 영역의 좌표를 네이버 클라우드 플랫폼 서버에 요청합니다. 앱의 계정 정보는 함께 보내지 않습니다.

## 6. 처리 위탁과 보관 장소
- 서버 호스팅: Amazon Web Services(Lightsail 서울 리전, 대한민국). 서버 운영에 필요한 범위에서 저장소와 연산을 제공합니다.
- 통화 중계 서버는 같은 서버에서 앱 운영자가 직접 운영합니다.
- 앱 운영자가 보관하는 개인정보는 대한민국 서버에서 처리합니다. 외부 추천 경로 계산에 제공한 좌표의 처리·보유 조건은 네이버 클라우드 플랫폼의 정책을 따릅니다. 운영자는 네이버 클라우드 플랫폼 Maps를 한국 리전에서 이용합니다.

## 7. 이용자와 법정대리인의 권리, 행사 방법
- 위치 공유는 언제든 끌 수 있고, 끄는 즉시 서버의 내 위치가 삭제됩니다.
- 열람·정정·삭제·처리 정지·동의 철회·계정 삭제는 아래 연락처로 요청하면 본인 확인 뒤 지체 없이 처리하고 결과를 알려 드립니다.
- 만 14세 미만 아동은 가입할 수 없으며, 가입 때 만 14세 이상임을 확인받습니다.

## 8. 안전성 확보 조치
- 비밀번호와 로그인 토큰은 해시 값으로만 저장합니다.
- 앱과 서버 사이 통신은 HTTPS 로 암호화합니다.
- 서버 기록에는 요청 본문·사진·인증 정보·위치 좌표를 남기지 않습니다.
